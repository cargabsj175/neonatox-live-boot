Boot Modes - Neonatox Live Boot

Official boot options and kernel flags for the Neonatox Live system

Overview

Neonatox Live provides multiple boot modes designed for normal usage, live system configuration, hardware compatibility, and low-level debugging.

All modes are selected from the GRUB boot menu and are implemented early in the boot process, primarily inside the initramfs.

Available Boot Modes

1. Live (Default)

linux /boot/vmlinuz quiet loglevel=3

Standard live boot mode intended for everyday use.

  • Minimal kernel output
  • Fast boot
  • No interactive configuration

2. Live (Language & Live User Config)

linux /boot/vmlinuz quiet neoconfig=1

Enables the interactive live configuration system during early boot.

  • Language selection
  • Keyboard layout
  • Timezone
  • Live user configuration
Note: This mode explicitly triggers the live configuration logic and does not affect other boot modes.

3. Live (Failsafe graphics)

linux /boot/vmlinuz quiet nomodeset vga=normal

Fallback graphics mode for systems with problematic or unsupported GPUs.

  • Disables kernel mode setting (KMS)
  • Improves compatibility with legacy hardware
  • Recommended for virtual machines and older systems

4. Live (DEBUG)

linux /boot/vmlinuz debug=1 loglevel=7

High-verbosity kernel debug mode.

  • Maximum kernel log output
  • Useful for driver, mount, and hardware debugging
  • May significantly slow down boot

5. Live (Initramfs debug)

linux /boot/vmlinuz initrd_debug=1

Debug mode for the initramfs stage.

  • Stops early boot process
  • Drops into an initramfs shell
  • Allows manual inspection of devices, mounts, and scripts
Important: This mode is intended for developers and advanced users. No automatic boot into the live system will occur unless manually continued.

Supported Kernel Flags

  • neoconfig=1 – Enables interactive live configuration
  • initrd_debug=1 – Opens an early initramfs debug shell
  • debug=1 – Enables kernel debugging
  • loglevel=7 – Maximum kernel log verbosity
  • nomodeset – Disables kernel mode setting
